# Security

## Report a Problem

If you find a security problem in this plugin, report it through GitHub's private vulnerability reporting: open the **Security** tab of this repository and choose **Report a vulnerability**. The report is not public. GitHub shows it to the people who administer this repository or manage its security, and to anyone they invite to help with the report.

Do not open a public issue for a security problem, and do not include anyone's personal data in a report.

## Scope

This repository holds only the plugin's text files: its manifests, its MCP server setting, and its instructions for assistants. A problem in the instructions that could make an assistant reveal, send, or change data counts, as does anything in these files that should not be public.

A problem in a LifeDB server, or in Claude Code or Codex, belongs to whoever makes that software.
